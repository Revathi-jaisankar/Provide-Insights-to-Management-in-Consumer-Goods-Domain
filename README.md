# Provide Insights to Management in Consumer Goods Domain(SQL Project) – Codebasics Resume Challenge

## 📌 Project Overview
This project analyzes **sales, products, customers, and business performance data** for **Atliq Hardwares**.  
The goal is to answer real business questions using SQL and generate insights through powerBI that support **data-driven decisions**.

---

## 📂 Dataset Description
The project uses several tables:

1. **dim_customer** – Contains customer-related data  
2. **dim_product** – Contains product-related data  
3. **fact_gross_price** – Contains gross price information for each product  
4. **fact_manufacturing_cost** – Contains the cost incurred in the production of each product  
5. **fact_pre_invoice_deductions** – Contains pre-invoice deductions information for each product  
6. **fact_sales_monthly** – Contains monthly sales data for each product  

---

## 🛠 Tools Used
- **MySQL**

## 📈 Key Insights
- **Q4 of FY2020** had the highest sales due to market recovery after COVID-19.  
- **Flipkart** received the highest discount at **30.87%** in 2021.  
- **Product count** increased by **36%** from 2020 to 2021.  
- **Retail channel** contributed **75% of total sales** in FY2021.
